# Threat Intelligence Investigation and Analysis of Malicious Hashes
This Threat Intelligence project for MedSecure Diagnostics Ltd. addresses the challenge of identifying malicious files within a dataset of suspicious SHA-256 hashes detected by the SOC.  The core objective is to detect and analyze malware using automation, combining PowerShell for hash collection and Python for threat intelligence enrichment. By leveraging tools such as VirusTotal and YARA, the project delivers measurable improvements in threat detection, incident response, and proactive defense against ransomware.  Expected Outcomes:  Rapid identification of malicious file(s)  Improved SOC investigation efficiency  Deployment of detection rules to prevent reinfection  Enhanced protection against supply-chain attacks  Business Context MedSecure Diagnostics Ltd., headquartered in Manchester, UK, is a healthcare provider specializing in diagnostic imaging, electronic medical records (EMR), and telehealth services.  As part of its digital transformation, the organization relies heavily on cloud infrastructure and third-party integrations. While these technologies improve service delivery, they also introduce increased cyber risk through expanded attack surfaces.  The organization faces growing threats from ransomware campaigns and supply-chain compromises, making proactive threat detection and response critical to maintaining operational continuity and protecting patient data.  Purpose of the Project The purpose of this project is to strengthen MedSecure’s ability to detect and respond to malware threats introduced through external integrations.  The project focuses on:  Identifying malicious hashes within large datasets  Enriching alerts using threat intelligence platforms  Correlating findings with known attack campaigns  Developing detection rules to prevent recurrence  This approach enables faster incident response, improved threat visibility, and stronger cybersecurity resilience.  Expected Outcomes Threat Detection: Identification of malicious hash within dataset  Incident Response: Faster and more accurate investigation  Security Improvement: Reduced risk of ransomware infection  Compliance: Improved alignment with healthcare data regulations  SOC Capability: Enhanced threat intelligence and automation skills
